# EJ Tech Solutions — Official Website

Live site: [ejtechno.com](https://ejtechno.com)

EJ Tech Solutions is a local IT and web services business serving Langley and Surrey, BC. This repository contains the source code for the official business website.

## Services

- IT Support — computer setup, troubleshooting, virus removal, data backup, PC builds
- Web Services — custom websites, Google Business Profile, SEO, maintenance
- Installations — dashcams, security cameras, smart home devices, TV mounting, WiFi setup

## Tech Stack

- [Next.js 15](https://nextjs.org) — React framework
- [Tailwind CSS](https://tailwindcss.com) — styling
- [Lucide React](https://lucide.dev) — icons
- [Formspree](https://formspree.io) — contact form
- [Vercel](https://vercel.com) — hosting and analytics

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.


## Deployment

Deployed automatically via Vercel on every push to `main`.
